# Inkory UI/UX Design Prompt (Version 1.0)

Design a complete, premium UI/UX for a commercial Print Shop Management System called **Inkory**.

This is NOT a student project, a template, or a generic dashboard. It is real software that will be used every day inside a printing shop. The design should feel polished, trustworthy, modern, and comparable to premium SaaS products such as Apple, Linear, Stripe Dashboard, Framer, Arc Browser, and Notion.

The application is Version 1.0 and consists of only two interfaces:

1. Customer Portal (Walk-in Customers)
2. Admin Dashboard

No online delivery, customer accounts, customer login, delivery tracking, or home delivery features should be included. Those features are intentionally removed and will be part of a future version.

FINAL GOAL

The final design should make customers feel like they are using premium commercial software rather than a local print shop website. Every screen should be clean, elegant, consistent, and highly polished. Prioritize simplicity, usability, accessibility, and professionalism over visual clutter. The finished design should be realistic enough that developers can build it directly without redesigning any part of the user experience.
